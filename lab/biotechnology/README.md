# Біотехнологія в агросфері — Інтерактивні математичні моделі та візуалізації (ЛР 1–55)

Інтерактивний віртуальний практикум (13 тематичних модулів, 55 лабораторних робіт, 35 математичних моделей у реальному часі на HTML5 Canvas) за навчальним посібником кафедри фізіології, біохімії рослин та біоенергетики НУБіП України:

> **Мельничук М. Д., Кляченко О. Л.** *Біотехнологія в агросфері: навчальний посібник для студентів вищих навчальних закладів.* — Київ: НУБіП України, 2014. — 269 с.

Розроблено у єдиній дизайн-системі та архітектурі сайту кафедри **[nubipfbr.online](https://nubipfbr.online/)**.

## Структура проєкту та інтеграція

- `index.html` — автономна точка входу для запуску практикуму з кореня репозиторію (GitHub Pages).
- `lab/biotechnology/index.html` — точка входу зі шляхами `../../assets/...` для прямого копіювання у підкаталог `lab/biotechnology/` сайту `nubipfbr.online`.
- `assets/css/biotechnology.css` — стилістичне розширення в палітрі кафедри (смарагдовий `#1E6B43`, бурштиновий `#B86B14`, темна/світла теми).
- `assets/js/lab/biotechnology.js` — графічне та математичне ядро (`window.BIO`: HiDPI Canvas `Stage`, спектральний колориметр CIE 1931 `Spectral`, графічний рушій `drawChart`, примітиви `Gfx`, реактивні контролери `UI`, маршрутизатор `App`).
- `assets/js/lab/biotech/lab-01.js` … `lab-13.js` — 13 модулів лабораторних робіт.
