# Рекламні флаєри й буклет кафедри

Готові файли до друку — у `out/`: **PDF** (вектор, до друку), **SVG** (вектор, самодостатній — зі шрифтами,
логотипами й фото, відкривається в браузері, Inkscape, Illustrator), **PNG** (перегляд).

Друк двосторонній: `…-1-front` — лицьовий бік, `…-2-back` — зворотний.

## Перший раунд (A5, A4-буклет, DL односторонній; бриф — `BRIEF.md`)

| Варіант | Формат | Файли |
|---|---|---|
| 1. «Зелена лабораторія» — світлий ботанічний | A5, 148×210 мм | `out/v1-botanica.*` |
| 2. «Нічна лабораторія» — темний, реактиви, мікроскоп | A5, 148×210 мм | `out/v2-nightlab.*` |
| 3. «Академічний» — буклет у три складання (рулон), 2 сторони | A4, 297×210 мм | `out/v3-booklet-1-outside.*`, `out/v3-booklet-2-inside.*` |
| 4. «Гербарій науковця» — ботанічна таблиця | A5, 148×210 мм | `out/v4-herbarium.*` |
| 5. «Енергія рослин» — хлоропласт, фотобіореактор | DL (єврофлаєр), 99×210 мм | `out/v5-energy.*` |

Буклет (варіант 3): друк двосторонній, перевертання по короткому краю; зовнішній бік — [клапан 97 мм | задня
сторінка 100 мм | обкладинка 100 мм], внутрішній — три панелі по 99 мм.

Макети без вильотів (bleed): для друку «в край» у друкарні попросіть додати 3 мм або друкуйте з білими полями.

## Як змінити

- Тексти й факти — `BRIEF.md`; спільні логотипи, QR-коди, шрифти — `kit/` (`python3 kit/make_kit.py`).
- Макети — генератори `src/gen_<назва>.py` → `src/<назва>.svg` → `python3 build.py <назва>`
  (збирає `out/`, перевіряє, що кожен QR-код зчитується).
- Потрібно: Python 3 із `segno`, `fonttools`, `brotli`, `opencv-python-headless`; Node.js із Playwright.
