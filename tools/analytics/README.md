# Статистика сайту з Google Analytics 4

`ga4-stats.R` будує графіки відвідуваності сайту за даними GA4 (Google Analytics 4).
Дані він бере через Google Analytics Data API (інтерфейс програмування для читання звітів GA4).

## Одноразове налаштування: власний Google Cloud-проєкт

У спільному проєкті, який googleAnalyticsR використовує за замовчуванням, Data API вимкнений,
тому запит повертає помилку `http_403 Google Analytics Data API has not been used in project …`.
Щоб її позбутися, потрібен свій проєкт. Нижче вказано назви пунктів в англомовному інтерфейсі консолі.

1. **Створіть проєкт.** Відкрийте <https://console.cloud.google.com/projectcreate>, введіть назву
   (наприклад, `kafedra-analytics`) і натисніть **Create**. Угорі консолі переконайтеся, що вибрано саме цей проєкт.
2. **Увімкніть API.** На сторінці <https://console.cloud.google.com/apis/library/analyticsdata.googleapis.com>
   натисніть **Enable**.
3. **Налаштуйте екран згоди** (OAuth consent screen — вікно, де Google питає дозвіл на доступ).
   Він налаштовується на <https://console.cloud.google.com/auth/overview>.
   - Тип користувачів: **External**. Вкажіть назву застосунку і свою пошту.
   - У розділі **Audience → Test users** додайте свій Google-акаунт, через який ви входите в GA.
4. **Створіть ключ OAuth-клієнта** (OAuth — протокол входу через Google).
   - Відкрийте <https://console.cloud.google.com/auth/clients>, натисніть **Create client**
     і виберіть тип **Desktop app**.
   - Натисніть **Download JSON** і збережіть файл, наприклад, як
     `C:/Users/<користувач>/Documents/ga-client.json`.
   - **Не додавайте цей файл у репозиторій.**
5. **Підставте шлях у скрипт.** У `ga4-stats.R` впишіть шлях до файлу в рядок `client_json <- "…"`.
   Потім запустіть скрипт кнопкою **Source**. Відкриється браузер: увійдіть і дозвольте доступ.
   Google покаже попередження, що застосунок не перевірено. Це очікувано, бо застосунок ваш власний:
   натисніть **Continue**.

Якщо ви щойно увімкнули API, а помилка 403 лишилася, зачекайте 2–5 хвилин.

Поки застосунок у режимі **Testing**, вхід діє 7 днів. Коли він закінчиться, браузер
попросить увійти знову.
