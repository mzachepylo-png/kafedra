# Кафедра фізіології, біохімії рослин та біоенергетики — НУБіП України

Сайт-лендінг кафедри для дистанційних лабораторних робіт: тут зібрано наочні приклади та моделі з дисциплін кафедри.

Статичний сайт (HTML + CSS + JS), без збірки та залежностей.

## Структура

```
index.html            — головна сторінка (лендінг)
modeling/index.html   — вкладка «Моделювання» (поки порожня)
assets/css/style.css  — стилі та кольорова палітра
assets/js/main.js     — мобільне меню
assets/js/models.js   — реєстр моделей для вкладки «Моделювання»
assets/img/logo.svg   — логотип / favicon
.github/workflows/pages.yml — мінімізація та публікація на GitHub Pages
```

## Запуск локально

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

## Публікація

GitHub Actions при кожному push мінімізує HTML/CSS/JS і публікує сайт на GitHub Pages.
Один раз увімкніть: **Settings → Pages → Source: GitHub Actions**.

## Вага сторінки

Без веб-шрифтів, фреймворків і зображень (лише вбудовані SVG). Після мінімізації та gzip
головна сторінка разом зі стилями і скриптами — близько 15 КБ. Біографії викладачів
розгортаються через нативний `<details>`, без JavaScript.

## Як додати модель

1. Створіть теку з моделлю, напр. `modeling/michaelis-menten/index.html`.
2. Додайте запис у масив `MODELS` в `assets/js/models.js` — картка з’явиться на сторінці «Моделювання» автоматично.
