# Кафедра фізіології, біохімії рослин та біоенергетики — НУБіП України

Сайт-лендінг кафедри для дистанційних лабораторних робіт: тут зібрано наочні приклади та моделі з дисциплін кафедри.

Статичний сайт (HTML + CSS + JS), без збірки та залежностей.

## Структура

```
index.html              — головна сторінка (лендінг)
modeling/index.html     — вкладка «Моделювання» (поки порожня)
microscope/index.html   — вкладка «Під мікроскопом», підрозділ «Хвороби рослин»
assets/css/style.css    — стилі та кольорова палітра
assets/js/main.js       — мобільне меню
assets/js/models.js     — реєстр моделей для вкладки «Моделювання»
assets/js/filter.js     — фільтр карток «Під мікроскопом» за типом збудника
assets/img/logo.svg     — логотип / favicon
assets/img/hero-lab.svg — ілюстрація головного екрана (колби, розсада)
assets/img/micro/       — мікрофото збудників (WebP)
.github/workflows/pages.yml — мінімізація та публікація на GitHub Pages
```

## Запуск локально

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

## Публікація

GitHub Actions при кожному push мінімізує HTML/CSS/JS і публікує сайт на GitHub Pages.
Один раз увімкніть: **Settings → Pages → Source: GitHub Actions**.

## Вага сторінки

Без веб-шрифтів і фреймворків. Після мінімізації та gzip головна сторінка разом зі стилями,
скриптами та SVG-ілюстрацією — близько 20 КБ. Біографії викладачів розгортаються через
нативний `<details>`, без JavaScript. Мікрофото на сторінці «Під мікроскопом» — WebP
(15 файлів, ~570 КБ разом), завантажуються ліниво (`loading="lazy"`) під час прокрутки.

## Як додати модель

1. Створіть теку з моделлю, напр. `modeling/michaelis-menten/index.html`.
2. Додайте запис у масив `MODELS` в `assets/js/models.js` — картка з’явиться на сторінці «Моделювання» автоматично.

## Як додати хворобу на сторінку «Під мікроскопом»

1. Покладіть зображення у `assets/img/micro/<id>.webp` (бажано до 900 px завширшки).
2. Скопіюйте в `microscope/index.html` будь-яку картку `<article class="micro">`, змініть `id`,
   `data-type` (`fungi`, `oomycetes`, `bacteria` або `viruses` — для фільтра), фото, підпис,
   опис, прояви та посилання на джерело у стилі APA.
3. Використовуйте лише зображення з відкритими ліцензіями (CC BY тощо) і вказуйте номер рисунка
   та ліцензію під цитатою.

## Джерела даних

Загальна інформація про кафедру — з офіційних матеріалів НУБіП України
(https://nubip.edu.ua/department/fbr-ta-b, сторінка факультету, освітня програма 162).
Склад кафедри, біографії та контакти викладачів — надані кафедрою.

Мікрофото на сторінці «Під мікроскопом» — фрагменти рисунків зі статей відкритого доступу
(ліцензії CC BY 2.0–4.0), знайдених через PubMed/PubMed Central та Europe PMC; під кожним фото —
бібліографічне посилання у стилі APA 7, номер рисунка та ліцензія. Добірку хвороб сформовано
за даними фітосанітарного моніторингу Держпродспоживслужби України.
