# Кафедра фізіології, біохімії рослин та біоенергетики — НУБіП України

Сайт-лендінг кафедри (факультет захисту рослин, біотехнологій та екології) з Онлайн лабораторією:
інтерактивні математичні моделі з теорією для лабораторних робіт студентів.

Статичний сайт: HTML + CSS + JavaScript (ES-модулі), без фреймворків, збірки та залежностей.
Формули — нативний MathML, графіки — власна легка бібліотека на Canvas.

## Структура

```
index.html                         — головна: привітання, коротко про кафедру, Онлайн лабораторія, наука, контакти
about/index.html                   — «Про кафедру»: кафедра сьогодні, історія кафедри (1898–2026), колектив,
                                     наука, історія факультету, адміністрація факультету, освітні програми
                                     (вкладки Бакалаврат / Магістратура / PhD)
lab/index.html                     — Онлайн лабораторія (хаб розділів)
lab/biochemistry/index.html        — розділ «Біохімія рослин» (список робіт)
lab/biochemistry/enzyme-kinetics/  — ЛР 1. Кінетика ферментативних реакцій
lab/biochemistry/temperature-ph/   — ЛР 2. Вплив температури і pH на активність ферментів
microscope/index.html              — «Під мікроскопом»: мікрофото збудників хвороб рослин
modeling/index.html                — переадресація зі старої адреси на lab/

assets/css/style.css               — дизайн-система (кольори, типографіка, компоненти)
assets/css/lab.css                 — стилі лабораторії (моделі, графіки, формули, експеримент)
assets/js/main.js                  — меню, вкладки, підсвічування розділів, анімація появи
assets/js/filter.js                — фільтр карток «Під мікроскопом»
assets/js/lab/plot.js              — графіки на Canvas (HiDPI, підказки, легенда)
assets/js/lab/ui.js                — повзунки, перемикачі, CSV-експорт, генератор варіантів
assets/js/lab/fit.js               — МНК, нелінійна регресія (Левенберг–Марквардт), Рунге–Кутта 4
assets/js/lab/<робота>.js          — модель конкретної лабораторної роботи
assets/img/nubip-logo.webp         — повний герб НУБіП (головна сторінка)
assets/img/nubip-shield.webp/.png  — щит герба (шапка, футер, значок вкладки)
```

## Запуск локально

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

ES-модулі не працюють при відкритті файлу напряму (`file://`), потрібен локальний сервер.

## Публікація

GitHub Actions мінімізує HTML/CSS/JS і публікує сайт на GitHub Pages
(`.github/workflows/pages.yml`). Один раз увімкніть: **Settings → Pages → Source: GitHub Actions**.

## Як додати лабораторну роботу

1. Скопіюйте теку наявної роботи, напр. `lab/biochemistry/enzyme-kinetics/` → `lab/biochemistry/<нова>/`.
2. Замініть теорію, формули (MathML), завдання й питання в `index.html`.
3. Створіть `assets/js/lab/<нова>.js`: імпортуйте `Plot` з `plot.js`, `sliders`/`segmented` з `ui.js`
   і опишіть модель.
4. Додайте картку `<a class="work">` у `lab/biochemistry/index.html`.

Віртуальний експеримент генерує дані детерміновано з рядка «Варіант» (прізвище або номер студента),
тож викладач, ввівши той самий рядок, бачить ті самі дані та еталонні відповіді.

## Як додати новий розділ лабораторії

Створіть теку `lab/<розділ>/index.html` за зразком `lab/biochemistry/` і додайте вкладку
`<a class="disc-tab">` та картку розділу в `lab/index.html`.
