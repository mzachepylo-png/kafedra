# Буфер обміну з пам'яттю і категоріями (аналог Win+V)

Програма на Python (tkinter). Для самого коду зовнішні бібліотеки не потрібні; іконка в треї й готовий `.exe` додатково використовують `pystray` та `Pillow`.

## Можливості

- **Автозапис** — усе, що ви копіюєте (текст), потрапляє в історію й зберігається між запусками.
- **Клік по запису** — текст одразу копіюється в буфер обміну; далі лишається натиснути Ctrl+V.
- **Категорії** — зліва панель категорій. Створіть категорію («＋ Нова категорія»), а потім:
  - **перетягніть** запис мишею на потрібну категорію, або
  - у меню запису («⋯» чи права кнопка) оберіть «Перемістити в категорію», або
  - натисніть «＋ Додати» — новий запис потрапить у відкриту категорію.

  Права кнопка по категорії — перейменувати чи видалити (записи не губляться, а стають «Без категорії»).
  Записи в категоріях і закріплені ★ не видаляються при переповненні історії та очищенні.
- **Гаряча клавіша** (лише Windows) — за замовчуванням **Ctrl+X** відкриває й ховає вікно біля курсора. Змінити: ⚙ → «Гаряча клавіша».
- **Фонова робота** — хрестик ховає вікно, програма лишається в треї (правою кнопкою: «Вийти»). Повторний запуск лише показує вікно вже запущеної копії.
- **Клавіатура:** `↑ ↓` — вибір, `Enter` — копіювати, `Esc` — очистити пошук / сховати вікно, `Delete` — видалити запис, `Ctrl+F` — пошук, `Ctrl+N` — новий запис.
- Пошук, «Пауза запису», «Завжди зверху», «Ховати вікно після копіювання» (⚙).

Дані лежать у `%APPDATA%\ClipboardMemory\` (`history.json` і `settings.json`); на Linux/macOS — `~/.local/share/clipboard-memory/`.

## ⚠ Про Ctrl+X

`Ctrl+X` у Windows — це «Вирізати». Поки програма запущена з цією гарячою клавішею, **вирізання в інших програмах не працює** (Word, браузер, Провідник): комбінацію забирає програма. Якщо це заважає — оберіть у ⚙ → «Гаряча клавіша» `Ctrl+Shift+X`, `Ctrl+Alt+V` або «Вимкнено». Звичайні Ctrl+C / Ctrl+V не зачіпаються. (`Win+V` зайняти неможливо — її резервує Windows.)

## Запуск

Готовий файл: `ClipboardMemory.exe` (збирається GitHub Actions — вкладка Actions → останній запуск → Artifacts).

З вихідного коду (потрібен Python 3.8+ з tkinter):

```bash
python clipboard_manager.py
```

Параметри: `--data ШЛЯХ` (інший файл історії), `--no-hotkey`, `--no-tray`, `--minimized` (запуститись одразу у фоні).
На Windows `run.bat` запускає без консолі. Щоб програма стартувала разом із Windows — покладіть ярлик на `ClipboardMemory.exe --minimized` у теку `shell:startup`.

## Важливо

- Історія зберігається на диску **відкритим текстом**. Паролі й токени краще не копіювати при увімкненому записі — є «Пауза запису» та видалення (✕).
- Запам'ятовується лише текст; картинки й файли ігноруються.
