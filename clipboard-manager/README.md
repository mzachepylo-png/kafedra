# Буфер обміну з пам'яттю (аналог Win+V)

Маленька програма на Python без зовнішніх залежностей (лише `tkinter`).

## Можливості

- **Автозапис** — усе, що ви копіюєте (текст), потрапляє в історію.
- **Клік по запису** — текст одразу копіюється в буфер обміну; після цього залишається лише вставити (Ctrl+V).
- **Власні шматки тексту** — введіть текст у поле зверху і натисніть «Додати» (або Ctrl+Enter). Такі записи автоматично закріплюються.
- **Закріплення ★** — закріплені записи завжди зверху й не видаляються при переповненні історії та очищенні.
- **Права кнопка миші** по запису — копіювати, закріпити, редагувати, видалити.
- **Пошук** по історії, **пауза запису**, **«Завжди зверху»**.
- **Пам'ять між запусками** — історія зберігається у JSON-файлі:
  - Windows: `%APPDATA%\ClipboardMemory\history.json`
  - Linux/macOS: `~/.local/share/clipboard-memory/history.json`
- Незакріплених записів зберігається до 300, однакові тексти не дублюються (піднімаються вгору).
- **Ctrl+Alt+V** (лише Windows) — показати вікно з-під інших програм. Саму `Win+V` програма зайняти не може — її резервує Windows.

## Запуск

Потрібен Python 3.8+ з tkinter (на Windows він є в інсталяторі з python.org; на Debian/Ubuntu: `sudo apt install python3-tk`).

```bash
python clipboard_manager.py
```

На Windows можна двічі клікнути `run.bat` — програма запуститься без консолі.

Параметри: `--data ШЛЯХ` (інший файл історії), `--no-hotkey` (без глобальної гарячої клавіші).

## Тести

```bash
python -m unittest -v
```

## Важливо

- Історія зберігається на диску **відкритим текстом**. Якщо копіюєте паролі чи токени — увімкніть «Пауза запису» або видаліть запис (✕).
- Зараз запам'ятовується лише текст; картинки й файли ігноруються.
- Закриття вікна (✕) завершує програму. Щоб вона працювала у фоні — просто згорніть вікно.
